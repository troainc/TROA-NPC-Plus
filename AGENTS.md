# Repository Guidance

This is the public-facing TROA NPC+ repository.

- Keep this repository source-free until TROA Inc. explicitly authorizes a public release.
- Do not add private source code, builds, DLLs, PDBs, game assets, internal API contracts, schemas, credentials, server configuration, or private project records.
- Public documentation must state only confirmed, high-level product direction and must avoid release-date promises.
- Update `README.md` and `CHANGELOG.md` for every user-visible change.
- Maintain `CONTEXT.md` and `LOGS.md` as concise project working records.
