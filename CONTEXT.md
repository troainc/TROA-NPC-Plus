# Project Context

## Purpose

This repository is the public information home for TROA NPC+, an in-development Torch and Space Engineers dedicated-server NPC simulation framework.

## Publication boundary

The public repository may contain approved high-level descriptions, roadmap updates, release notes, and future installation documentation. It must not contain source code, build artifacts, private assets, internal schemas or API contracts, credentials, server data, or unreleased configuration.

## Current state

Established 2026-09-15 as a coming-soon project page. No public build is available.
