# TROA NPC+ documentation

NPC+ is a pre-release project. There is no public build, package, installation procedure, or supported player command set today, so do not install files from this documentation repository as a plugin.

- Read the [project README](../README.md) for status and planned scope.
- Read the [public roadmap](ROADMAP.md) for intended development direction.
- Watch the repository for a release; installation and server-owner setup instructions will be published with an actual supported build.

The target platform is Torch and .NET Framework 4.8 x64. These are design targets, not a statement that a usable build is available.
