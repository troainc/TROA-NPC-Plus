# Bifrost Plugin Panel — TROA NPC+ status

Bifrost Plugin Panel is the operator interface hosted by TROA Admin Overseer inside Torch. TROA NPC+ is still pre-release and has no public installable build. Therefore NPC+ does not currently provide a supported Panel workspace, operator settings, metrics, commands, or gameplay controls.

After NPC+ has a public release and its Panel support is implemented and verified, server owners will be able to follow Admin Overseer’s Panel setup guide and check for an NPC+ workspace under **Plugin systems**. Until then, do not install an unreleased NPC+ package or rely on a Panel connection for NPC+ operations.

This note describes public project direction only. It does not publish an internal adapter contract or promise a release date or feature set. See the [TROA Admin Overseer public repository](https://github.com/troainc/TROA-Admin-Overseer) for general Panel setup when that becomes relevant.
