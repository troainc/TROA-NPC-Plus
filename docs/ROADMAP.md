# TROA NPC+ Public Roadmap

TROA NPC+ is in active development. This roadmap describes intended product direction, not a delivery guarantee or release schedule.

## Foundation

The first milestone is a reliable server-side foundation: persistent NPC identity, simulation state, lifecycle handling, world snapshots, safe game-thread integration, save-safe persistence, and performance controls.

## A living universe

Planned gameplay systems include factions, squads, fleets, territories, reputation, dynamic encounters, missions, and world events. The goal is a universe where NPC actions and player choices can leave durable consequences.

## Story and server authorship

NPC+ is intended to support first-party TROA content alongside server-authored lore and factions. Communities should be able to build original settings with clearly owned names and content, without being required to modify the core project.

The first announced TROA faction is the **Asgardian Concord**—commonly called the Asgardians.

## Content and compatibility

The planned content model is data-driven, allowing validated community and server content such as faction definitions, behavior profiles, fleets, encounters, missions, dialogue, and lore. Compatible server-side systems are expected to have a supported integration path when that surface is ready for release.

## Before release

Public builds will follow only after implementation, compatibility work, stability testing, documentation, and deployment guidance are ready. Until then, no public installation package is available.
